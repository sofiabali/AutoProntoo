🚗 AutoPronto – Sistema de Locadora de Veículos
Projeto acadêmico – IFSP (Desenvolvimento de Sistemas)

O AutoPronto é um sistema web desenvolvido como trabalho acadêmico para a disciplina do curso de Desenvolvimento de Sistemas – IFSP, com o objetivo de aplicar conhecimentos de Flask, SQLite, JavaScript, HTML/CSS, Jinja2 e lógica de programação.
O sistema simula uma locadora de veículos, permitindo que usuários realizem reservas, visualizem carros disponíveis e que administradores gerenciem o catálogo de veículos.

🎯 Objetivo do Projeto

Criar um sistema funcional de locadora que permita:
Exibir carros disponíveis para locação
Realizar reservas
Gerenciar veículos (adicionar, editar e remover)
Organizar tudo utilizando Flask, banco de dados SQLite e templates Jinja2
Aplicar conceitos de front-end com HTML, CSS e responsividade

🛠️ Tecnologias Utilizadas

Python (Flask) – estrutura principal do servidor
SQLite3 – banco de dados local
HTML5 – estrutura das páginas
CSS3 – estilização do site
Jinja2 – templates dinâmicos
JavaScript – interação em algumas páginas
